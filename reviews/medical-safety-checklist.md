# 의학 안전 체크리스트

이 문서는 본문이 의학적 단정·과장·불안 조장으로 빠지지 않았는지를 점검하기 위한 검수용 체크리스트다.
각 장의 원고가 완성되거나 확장될 때마다 아래 항목을 한 줄씩 통과시켜야 한다.

## 1. 단정 표현 점검

- [ ] "반드시", "확실히", "100%" 같은 의학적 단정 표현이 없는가
- [ ] "지능이 높아진다", "성공하는 아이", "머리가 좋아진다" 같은 효능 약속이 없는가
- [ ] 인과관계를 단언하는 대신 "연결된다", "관련이 있다", "영향을 줄 수 있다" 정도로 신중하게 풀었는가

## 2. 임상 정보의 범위

- [ ] 임신 주수·태아 발달 설명이 일반적으로 알려진 범위 안에 머무는가
- [ ] 진단·처방·치료에 해당하는 판단을 책이 대신하지 않는가
- [ ] 의심되는 증상이나 위험 신호는 "전문 의료진과 상담"으로 안내하는가

## 3. 청각·감각 서술

- [ ] 특정 음악·태교 음원이 효과를 보장한다는 식의 표현이 없는가
- [ ] 청각 발달 시점은 "임신 중기 이후 점차" 정도로 부드럽게 표현했는가
- [ ] 감각 자극의 양이 아니라 "반복성·안정감·정서"가 핵심이라는 논조가 유지되는가

## 4. 감정·스트레스 서술

- [ ] 엄마의 모든 부정적 감정이 곧 태아에 해를 끼친다는 식의 서술이 없는가
- [ ] 감정 표현보다 "조절과 회복"의 가능성을 강조하는가
- [ ] 죄책감을 자극하는 문장("좋은 엄마라면 반드시…")이 없는가

## 5. 전통 태교 해석

- [ ] 사주당 이씨와 『태교신기』를 신비주의로 포장하지 않았는가
- [ ] 전통의 통찰을 "오늘의 언어로 다시 읽는다"는 관점으로 풀고 있는가
- [ ] 전통적 금기 항목을 그대로 처방처럼 옮기지 않았는가

## 6. 독자 보호

- [ ] 임신 중인 독자가 읽었을 때 새로운 불안을 만들지 않는가
- [ ] 어떤 독자(유산 경험·고위험 임신 등)에게도 비난처럼 읽히지 않는가
- [ ] 글의 끝이 "안심·이해됨·해볼 수 있겠다"는 감정으로 닫히는가
