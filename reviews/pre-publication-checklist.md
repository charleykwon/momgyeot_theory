## D. 메타·메모 블록 (마크다운에만, HTML에서는 자동 제거됨)

| 파일 | 위치 | 내용 |
|---|---|---|
| `docs/02-sajudang-intro.md` | line 513–519 | `## revision note` 블록 (5개 항목) — 빌더가 strip 처리 |
| `docs/02-sajudang-intro.md` | line 542 | `> 메모: _refs/manuscript.txt …` |
| `CLAUDE.md` | line 76 | "자료 URL은 추측해 적지 않는다. 자료명만 정확히 적고, 출간 전 검수자가 URL과 서지 정보를 채운다." |
| `CLAUDE.md` | line 139–140 | 검수자 패키지·안내문 템플릿 참조 |

**판단:** `## revision note`는 빌더 정규식 `\n---\s*\n##\s*revision note.*?` 으로 자동 strip되어 HTML 본문에는 노출되지 않는다. `CLAUDE.md`는 작업 가이드라 그대로 두는 것이 맞음. `> 메모:` 인용 블록은 HTML에 노출되므로 출간 전에 제거 또는 HTML 주석화 필요.

## E. 요약 — 출간 전 처리 가짓수

| 종류 | 건수 | 처리 방향 |
|---|---|---|
| 챕터 끝 메타 안내 문단(A) | 9건 | HTML에 노출 안 됨. 마크다운 그대로 둬도 무방. |
| 각주 안 작업 메모(B) | 23개 각주 | **검수자가 표준 서지로 교체** — 본 차수 작업 범위 밖, 검수 완료 후 처리 |
| 부록 D 안내(C) | 1건 | 본 차수에서 안전 박스로 강화 + 1차 자원으로 채움 |
| revision note / 메모(D) | 3곳 | 빌더가 자동 처리 (1곳은 출간 전 수동 제거 권장) |

**전체 23개 각주 + 1개 부록 항목**이 검수 완료 시점에 표준 서지로 치환되어야 한다. 그 작업은 의학·한국학·가족학 검수자가 각 자료를 1차 확인해 진행한다 (`reviews/medical-reviewer-package.md` 참고).
