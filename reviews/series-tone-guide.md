# 맘곁 태교 시리즈 톤 가이드 1.0

- 작성일: 2026-04-28
- 적용 대상: 『맘곁 태교 — 이론편』 / 『맘곁 태교 — 실천편』(『새로 쓰는 태교신기』 시리즈)
- 목적: 두 책의 *어조 자체*는 각자의 결을 유지하되, 시리즈 정합성을 만드는 **4개 앵커**를 통일한다.

---

## 가이드의 자리

이 시리즈는 두 권이 *다른 결*을 가진 채로 *같은 자리*를 향한다는 디자인이다.

| 책 | 어조 | 강점 |
|---|---|---|
| 이론편 | 평서체 산문 + 도표·각주 | 사색·근거·헤리티지 — *마음의 지도* |
| 실천편 | 정중체 + 친근체 + 태담 + 이모지 | 동반·일상·실천 — *하루씩 걸어 보는 책* |

어미는 통일하지 않는다. 통일하면 두 책이 모두 약해진다.
대신 **사실·인용·핵심 어휘·안전 라인** 네 자리에서 같은 결을 갖는다.
어미보다 *단어와 사실*이 시리즈 정합성을 결정한다.

---

## 앵커 1 — 사주당 인용 표준 표기

같은 절을 두 책이 다르게 옮기면 독자가 혼란스럽다. 자주 인용되는 핵심 절의 표준 한국어 의역을 정한다. 검수자가 채울 때 한문 원문·한글 음의본·번역 판본은 별도 표기.

### 표준 의역 표

| 절 | 짧은 형(인라인 인용) | 긴 형(박스 인용) |
|---|---|---|
| **1장 2절** (교육의 시작점) | 스승의 십 년 가르침도 어머니의 열 달 가르침만 못하고, 어머니의 열 달도 아버지의 하루만 못하다. | 훌륭한 의사는 병이 나기 전에 손을 쓰고, 훌륭한 교사는 아직 태어나기 전에 가르친다. 그러므로 어진 스승의 십 년 가르침도 어머니의 열 달 가르침만 못하고, 어머니의 열 달도 아버지의 하루만 못하다. |
| **1장 3절** (아버지의 자리, 잉태 시) | 잉태할 때 아비의 정과 마음가짐이 자식의 골격을 이룬다. | (그대로 사용) |
| **1장 4절** (자궁 = 학습 환경) | 자궁은 원초적 교육의 자리이며, 어미의 덕이 곧 자식의 살이 된다. | (그대로 사용) |
| **4장 1절** (온 가족이 함께) | 태교는 어머니 혼자 하는 것이 아니다 (胎之敎, 非母獨爲也). | 태지교, 비모독위야(胎之敎, 非母獨爲也). 태교는 어머니 혼자 하는 것이 아니다. 한 집안 사람 모두가 자신의 행동을 삼간다. |
| **4장 4절** (보고 듣는 것) | 임신부는 듣는 것을 삼간다. 시 읊는 소리와 책 읽는 소리가 좋다. | (그대로 사용) |
| **4장 5절** (마음가짐 7가지) | 임신부는 일곱 가지 마음을 삼간다 — 해코지·살의·간교·기만·탐욕·시기·험담. | (그대로 사용) |
| **4장 12절** (섭생) | 엄마의 영양이 곧 태아의 영양이다. | 엄마의 영양이 곧 태아의 영양이다. 흉한 모양·벌레먹은 것·찬밥·쉰 것·과한 육식·술·말고기·비늘 없는 생선은 피한다. |
| **5장 1절** (절제·일관성) | 태교의 요점은 삼가 함(愼)에 있다. | (그대로 사용) |
| **5장 2절** (자기효능감) | 스스로 구하면 얻을 수 있다. | (그대로 사용) |
| **8장 2절** (자기수용) | 태교를 다 실행하지 못함을 탄식한다. | (그대로 사용) |
| **9장 1절** (기록 문화) | 옛 사람은 옥판에 새겨 보관했다. | (그대로 사용) |
| **10장 1절** (장부의 책임) | 태교의 책임은 장부에게 있다. 어진 배우자를 가까이 해야 한다. | (그대로 사용) |

### 운영 원칙

- 박스 인용은 *시작 절·끝 절 명시 + 출처 표기*. 예: `> 임신부는 듣는 것을 삼간다… — 사주당 이씨, 『태교신기』 4장 4절`
- 인라인 인용은 *짧은 형*으로만. 긴 형을 본문에 풀어 쓰지 않는다.
- 한문 단독 노출 금지. 반드시 *한문 + 한국어 의역* 쌍으로.
- 다른 표현이 필요할 때는 *이 표를 v1.1로 갱신해 두 책 동시 적용*. 한쪽만 따로 가지 않는다.

## 앵커 2 — 의학 단정 헤지 표준

같은 사실을 한 책은 단정으로, 다른 책은 가능성으로 말하면 신뢰가 흔들린다. 두 책 모두 같은 헤지 톤을 쓴다.

### 3단계 강도 기준

| 강도 | 사용 자리 | 표현 예시 |
|---|---|---|
| **합의** | 의학 교과서 수준의 일반 합의 | *"~로 알려져 있다", "~로 설명된다"* |
| **가능성** | 연구가 진행 중이거나 인과 단정이 어려운 자리 | *"~할 수 있다는 보고가 있다", "~를 시사한다", "~와 관련될 수 있다"* |
| **개인차** | 사람마다 다른 자리 | *"사람마다 다를 수 있다", "구체적 결정은 의료진과 함께"* |

### 자주 쓰이는 자리의 표준 표현

| 주제 | ❌ 피할 표현 | ✅ 표준 표현 |
|---|---|---|
| 청각 발달 시기 | 16주부터 듣는다 / 24주에 구별한다 | 임신 중기 무렵부터 점차 반응하고, 후기로 갈수록 친숙한 소리를 더 또렷이 구별하는 것으로 보고된다 |
| 모성 스트레스 영향 | 스트레스가 아이에게 해를 끼친다 | 모성 스트레스 반응(HPA 축·코르티솔 등)이 태내 환경의 신호를 바꿀 수 있는 가능한 통로 가운데 하나로 제안되어 왔다 |
| 부정적 감정 | 부정적 감정은 태아에 나쁘다 | 모든 부정적 감정이 곧바로 나쁜 결과를 만든다고 말하지 않는다. 정서 조절·회복·사회적 지지가 보호 요인으로 작용할 수 있다 |
| 산전·산후 우울 비율 | X%가 우울에 걸린다 | 10명 가운데 1~2명 정도가 비슷한 시기를 통과한다는 보고가 있다 |
| 부성 후성유전 | 아빠 습관이 자녀를 결정한다 | 부계의 임신 전 생활 습관이 정자의 후성유전적 표지에 미세 변화를 만들 수 있다는 가능성이 시사되어 왔다 |
| 운동 권고 | 매일 30분 운동해야 한다 | 합병증이 없는 임신의 경우 중간 강도의 활동이 권장될 수 있다. 종류·강도는 산부인과 진료에서 의료진과 함께 결정한다 |
| 음식 회피 | 절대 먹으면 안 된다 | 주요 의학 단체들이 일반적으로 권하는 회피 항목이 있다(알코올·날것·일부 고수은어 등) |
| 효능 약속 | 음악 들려주면 머리가 좋아진다 | 음악의 종류보다 반복되는 일상의 결과 그 안에 담긴 정서가 더 또렷이 닿는다 |

### 통계 인용의 톤

- 비율 단정 ❌ → *"적지 않은 임신부가 비슷한 시기를 통과한다"* / *"지속적으로 늘어 왔다"*
- 출처는 학술지·공공 보고서로 좁히고, 비학술 웹 출처는 사용하지 않는다.
- 출간 시점에 정확한 수치를 검수자가 채우되, 본문은 *추세 진술* 톤을 유지.

## 앵커 3 — 공통 어휘

같은 가치관을 다른 단어로 부르면 시리즈 정체성이 약해진다. 두 책이 공통으로 사용하는 어휘를 합의한다.

### 브랜드 표기

| 자리 | 표기 |
|---|---|
| 회사 | 바비즈코리아 |
| 태교·임신 시기 브랜드 | 맘곁 |
| 모유수유·산후·영유아기 브랜드 | 마더스베이비 |
| 시리즈 명 | 맘곁 태교 (이론편 / 실천편) |

본문에서 회사명을 호명할 자리는 거의 없다(부록·판권에서만 사용). 본문에서는 시리즈명·브랜드명이 자연스럽게 등장한다.

### 핵심 어휘 가족

| 키워드 | 의미·결 |
|---|---|
| **자리** | 위치·관점·맥락을 모두 아우르는 다목적 어휘. *"~의 자리에 머문다"* |
| **결** | 톤·분위기·흐름의 미세한 모양. *"하루의 결을 다정하게"* |
| **연결** | 엄마와 태아, 가족과 임신부의 관계 — 다섯 원칙의 첫 자리 |
| **환경** | 사주당의 핵심 개념 — 사실·구조·연구 차원의 단어. 학술 진술과 핵심 명제에 사용 |
| **분위기** | *환경*과 결이 다른 자매 어휘 — 일상의 결, 가족·집안의 공기. *환경*보다 부드럽고 가까운 자리에 사용 |
| **관계** | 태교의 본질을 가리키는 핵심어. *"활동이 아니라 관계"* |
| **곁** | 함께 머무는 자리. *"엄마 곁에 가족이 있다"* |
| **마음이 편안해지는 구조** | 맘곁 시그너처. 본문 곳곳에 일관 등장 |
| **한 가지부터 해도 충분하다** | release line. 다섯 원칙·체크리스트 끝에 일관 등장 |
| **다정한** | *친절한*보다 *다정한* 우선 — 친밀하면서 느슨한 결 |

### 지양 어휘

- 단정·과장·영웅화: *반드시·절대·무조건·완벽·최고·비결·효과 보장·성공하는 아이·선구자·혁명적·세계 최초* 등
- 차가운 학술 어휘는 *풀어 쓴 한국어*로. 전문 용어가 꼭 필요하면 한 번만 등장 + 풀이 병기.
- **예외 — negation/release 자리는 허용**. *"완벽하지 않아도 괜찮다"·"한 가지를 완벽하게 지키려 애쓰기보다"* 같이 *부정·해방을 만드는 자리*에서 지양 어휘를 사용하면 메시지가 더 또렷해진다. 이 경우는 단정이 아니라 *단정의 회피*이므로 가이드 위반이 아니다.
- **예외 — 사주당 인용 안의 단정**. 사주당이 본인의 어조로 단정한 자리(*"반드시 태교를 해야 한다"* 등)는 인용의 원문 톤을 보존한다. 본문이 그 톤을 받아 쓰지 않으면 된다.

## 앵커 4 — 안전 라인 표준

두 책 모두 임신부의 안전·정서를 우선한다. 같은 위치에 같은 톤으로 안전 라인을 둔다.

### 표준 안전 표현

| 자리 | 표준 문장 |
|---|---|
| **전문가 상담 권유** | 힘든 마음이 길어지거나 일상에 지장을 줄 만큼 무거워질 때는 (산부인과·정신건강 전문가와) 상의하는 것을 권한다. 도움을 청하는 일은 약함이 아니라, 자신과 아이를 함께 돌보려는 적극적인 태도다. |
| **비난 차단 헤지** | 이 장은 (~을 경험해 온 / ~에 닿지 못한) 독자를 비난하지 않는다. 오히려 그런 시간을 지나고 있는 독자에게 조금 더 부드러운 시선이 닿기를 바라며 쓰인다. |
| **다양한 가족 형태 인정** | 가족의 형태는 사람마다 다르다. 한부모 가정·조손 가정·새로운 형태의 가족도 그 자리에 함께 선다. 이 글이 또 다른 부담으로 닿지 않기를 바란다. |
| **유산·고위험 임신 보호** | 이 글은 모든 독자가 같은 임신 경험을 하고 있다고 전제하지 않는다. 더 어려운 시간을 지나 온 독자에게도 또 다른 부담이 되지 않기를 바란다. |
| **의료 처방 비대신** | 이 책(글)은 의학적 처방이나 개별 진료를 대신하지 않는다. 구체적 결정은 산부인과 진료에서 의료진과 함께 내려야 한다. |

### 안전 라인의 위치

| 자리 | 이론편 | 실천편 권장 |
|---|---|---|
| 정서 영역(엄마의 감정·산후 우울) | 6장 / 9장 | 정서 다루는 PART 도입 또는 끝 |
| 가족 형태 인정 | 7·8장 도입 | 가족·아빠 다루는 PART 도입 |
| 의료 처방 비대신 | 4장 도입 / 부록 D | 식·운동·잠 다루는 PART 도입 |
| 유산·고위험 임신 보호 | 6장 도입 | 임신 초기·정서 PART 도입 |
| 전문가 상담 권유 | 5·7·8·9·10장 본문 끝 | 각 PART 마무리 |

## 적용 체크리스트

새 원고나 개정 원고에 이 가이드를 적용할 때 사용한다.

### 사주당 인용 점검

- [ ] 본문에 등장하는 사주당 인용이 위 표준 의역 표와 일치하는가
- [ ] 한문이 단독 노출되지 않고 한국어 의역과 함께 있는가
- [ ] 박스 인용에 *책명·장·절·저자* 출처가 표기되어 있는가
- [ ] 짧은 형/긴 형의 사용 자리가 적절한가

### 의학 헤지 점검

- [ ] 단정·과장·효능 약속 어휘가 본문에 없는가
- [ ] 시기 단정(주차 단위)을 피하고 일반 합의 톤을 유지했는가
- [ ] 통계 인용이 *불안 자극이 아닌* 톤으로 풀려 있는가
- [ ] 의료적 결정을 *의료진과 함께*로 안내하는가

### 공통 어휘 점검

- [ ] 브랜드 표기가 가이드대로인가(맘곁 / 마더스베이비 / 바비즈코리아)
- [ ] 핵심 어휘 가족(자리·결·연결·환경·관계·곁)이 자연스럽게 등장하는가
- [ ] 지양 어휘가 사용되지 않았는가
- [ ] 학술 용어는 한 번 등장 + 풀이 병기 원칙을 지키는가

### 안전 라인 점검

- [ ] 정서·가족·의료·고위험 임신 영역에 표준 안전 라인이 적절한 위치에 있는가
- [ ] 전문가 상담 권유 표현이 표준 문장과 일치하는가
- [ ] 다양한 가족 형태·유산·고위험 임신 헤지가 필요한 자리에 빠지지 않았는가

- 새 인용·새 사실·새 어휘가 들어올 때, 두 책 동시 적용을 원칙으로 삼는다.
- 가이드 갱신은 *시리즈 책임자*가 합의 후 v1.1, v1.2로 버전을 올린다.
- 이 가이드의 4개 앵커가 흔들리면 시리즈 정합성도 흔들린다. 어미가 다른 것은 디자인이지만, 이 4개는 통일이다.
